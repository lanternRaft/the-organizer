# The Organizer

Whiteboard/canvas tool for world building with 4 primary elements uses tldraw as core library

## Elements
- Nodes
- Labels
- Arrows
- Keys

## Keys
Menu with a little button to assign meanings to different colors of nodes, labels and arrows

## Nodes
- Little colorable points
- Cannot be adjusted except for color

## Arrows
- Colorable lines
- Pass through nodes and arrows in their path
- Three types
    - no direction (no head)
    - mono direction (1 head)
    - dual direction (2 heads)

## Labels
- Size and shape are adjustable
- Colorable

## Circle/Ovals
- Can place around
- Connect to arrows
- Put text on them

## Other Notes
- Light and Dark mode
- Background grid that can be enabled and disabled
